Features

Your whole desktop, at a glance.

Find, focus, and move windows without breaking your flow.

Live window thumbnails

Real captures through hyprland-toplevel-export-v1, not static icons or placeholder rectangles.

Keyboard-first

Arrow keys or hjkl, number jumps, and Tab cycling across every workspace, starting from the focused window.

Type to filter

Filter by workspace name, app class, or window title. Non-matching windows dim while the match stays in focus.

Move windows fast

Press m to send the active window to the selected workspace, then follow it there if you want.

App icons and tooltips

Icons resolve from your icon theme and .desktop files. Hover a window for its app name, class, and title.

Config that stays out of the way

Sensible defaults, a TOML file only when you need it, and live reload on save or SIGHUP.

How it works

One daemon. One overlay. Zero plugins.

1

Start the daemon

hyprview takes a single-instance lock and waits quietly in ppoll, using almost no CPU while hidden.

2

Toggle the overlay

On SIGUSR1 it creates a fullscreen wlr-layer-shell surface and asks Hyprland for its workspaces and windows.

3

See live thumbnails

Cards appear immediately, then thumbnails stream in one at a time without blocking input or the event loop.

Install

Build it, then bind it.

The AUR package is not published yet. Both paths below build the same binary.

Arch Linux

Use the tracked hyprview-git package from the repository.

git clone https://github.com/nnthnn/hyprview.git
cd hyprview/packaging/aur/hyprview-git
makepkg -si

From source

You need a Rust toolchain, pkg-config, and the Wayland, Cairo, and Pango development headers.

git clone https://github.com/nnthnn/hyprview.git
cd hyprview
cargo build --release

sudo install -Dm755 target/release/hyprview \
  /usr/local/bin/hyprview

Debian/Ubuntu build dependencies: cargo pkg-config libwayland-dev libpango1.0-dev. Arch: base-devel rust wayland pango.

Also works on Sway in fallback mode: workspace data over i3 IPC, with coloured placeholders instead of live thumbnails.

Configure

Make it yours.

hyprview reads $XDG_CONFIG_HOME/hyprview/config.toml and falls back to ~/.config/hyprview/config.toml. Every key is optional, and the file is watched for changes.

See the full configuration reference for colors, fonts, layout, keybindings, and behavior.

Example config
Hyprland 0.55+ · hyprland.lua
hl.on("hyprland.start", function()
    hl.exec_cmd("hyprview")
end)

hl.bind("SUPER + Tab", hl.dsp.exec_cmd("hyprview --toggle"))
~/.config/hyprview/config.toml
[appearance]
show_app_icons = true
icon_size = 20.0

[behavior]
allow_mouse = false
switch_on_move = true

[keybindings]
move_window = "m"
tab = "Tab"

The keyboard is the interface.
