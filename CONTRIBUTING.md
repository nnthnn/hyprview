# Contributing

Thanks for helping improve hyprview.

- Bug reports and feature requests: open an issue at
  <https://github.com/nnthnn/hyprview/issues>.
- Before sending a pull request, run `just check` to verify formatting, lints,
  and the unit tests.
- Build and test commands, architecture notes, packaging, and release details
  live in [`docs/development.md`](docs/development.md).
- Code invariants and conventions are in [`AGENTS.md`](AGENTS.md).
- Describe user-visible changes in the `Unreleased` section of
  [`CHANGELOG.md`](CHANGELOG.md).

Commit messages use an imperative subject and a body explaining the reasoning
behind the change.
